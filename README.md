## 🌟 About the Project

Luffy Gear 5 Transformation is a creative and interactive web project inspired by one of the most iconic moments in the anime *One Piece*.

This project brings the legendary Gear 5 awakening to life through interactive mouse effects, canvas-based visuals, smooth animations, and an immersive interface.

## ✨ Features

- ⚡ Interactive Gear 5 reveal experience.
- 🎨 Dynamic visuals using HTML5 Canvas.
- 🖱️ Mouse-controlled visual interaction.
- 🌊 Smooth pointer movement and trail effects.
- 🔥 Anime-inspired interface and visual effects.
- 📱 Responsive web design.
- 🚀 Lightweight frontend implementation.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/harishgummadi72/luffy-tranformation.git
```

### Navigate to the Project

```bash
cd luffy-tranformation
```

### Run the Project

Open `luffy.html` in your web browser.

You can also use the Live Server extension in Visual Studio Code.

## 🎮 How to Use

1. Open the project in your browser.
2. Explore the interactive interface.
3. Move your mouse across the screen.
4. Experience the Gear 5 reveal animation.

## 🎯 Project Objective

The main objective is to explore frontend development, creative JavaScript interactions, canvas rendering, and animation techniques while building an engaging anime-inspired web experience.
